# Data

The dataset is not stored in this repository.

Source: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia

`src.dataset.find_data_root()` looks for the data in this order:

1. the folder in the `XRAY_DATA_ROOT` environment variable
2. `data/chest_xray/` (a manual download that contains `train/`, `val/`, `test/`)
3. an automatic download with `kagglehub` (needs `KAGGLE_USERNAME` and `KAGGLE_KEY`, or Colab secrets)

`data/splits/manifest.csv` is generated by `notebooks/01_eda.ipynb` and committed. It lists every image with its split, patient group, hash and drop reason.
